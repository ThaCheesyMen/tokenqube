## 🎨 **Color Guide**

### **Widget Headers:**
- 🟣 **Purple Gradient:** Gaming Sessions (`from-purple-500 to-purple-600`)
- 🔵 **Blue Gradient:** Quests (`from-blue-500 to-cyan-500`)
- 🟡 **Yellow Gradient:** Achievements (`from-yellow-500 to-orange-500`)
- 🟢 **Green Gradient:** Referrals, Buy/Sell (`from-green-500 to-emerald-600`)
- 🔴 **Pink Gradient:** Token Staking (`from-pink-500 to-purple-600`)
- 🔷 **Cyan Gradient:** Transactions (`from-blue-500 to-cyan-500`)

### **Stats Colors:**
- **Green** (`text-green-400`): Positive values, earnings
- **Red** (`text-red-400`): Negative values, spending
- **Yellow** (`text-yellow-400`): Tokens, currency
- **Blue** (`text-blue-400`): XP, experience
- **Purple** (`text-purple-400`): Special rewards

---

## 📐 **Layout Dimensions**

### **Widget Heights:**
- **Minimum:** 320px (mobile)
- **Recommended:** 400-500px (desktop)
- **Maximum:** Auto (based on content)

### **Grid Gaps:**
- **Between widgets:** 24px (`gap-6`)
- **Between rows:** 24px (`space-y-6`)
- **Internal padding:** 24px (`p-6`)

### **Responsive Breakpoints:**
```css
/* Mobile: < 1024px */
grid-cols-1

/* Desktop: >= 1024px */
lg:grid-cols-2
```

## 🎯 **Interactive Elements**

### **Hover States:**
All interactive elements have hover effects:
- **Widgets:** Border changes to purple on hover
- **Buttons:** Opacity 90% or color shift
- **Cards:** Scale 105% on hover (staking plans)
- **Links:** Text color changes

### **Click Targets:**
- **"View All" buttons:** Top-right of each widget
- **Quick Actions:** Horizontal button bar
- **Share buttons:** In referral widget
- **Copy buttons:** Next to referral code and link

### **Visual Feedback:**
- ✅ **Checkmarks:** Completed items
- 🔒 **Locks:** Locked achievements
- 🔴 **Dots:** Notification badges
- ⏳ **Timers:** Countdown for unlocks
- 📊 **Progress bars:** Challenge completion

## ⚡ **Quick Reference**

### **Widget Sections:**
1. **Header** - Icon, title, description, "View All" button
2. **Stats Grid** - 2-3 key metrics
3. **Content Area** - Recent/featured items
4. **Info Banner** - Tips, rewards info
5. **Action Buttons** - Primary actions

### **Data Sources:**
- **Gaming Sessions:** `gaming_activity` table
- **Quests:** `quest_templates`, `user_quests` tables
- **Achievements:** `platform_achievements`, `user_achievements` tables
- **Transactions:** `transactions` table
- **Staking:** `token_staking` table
- **Referrals:** `profiles.referral_code`, `referral_stats`

### **Key Features Per Widget:**
```
Gaming:      5 recent sessions, today's stats
Quests:      4 active quests, difficulty badges
Staking:     3 plans, active stakes
Buy/Sell:    3 packages, sell calculator
Achievements: 4 featured, progress stats
Transactions: 5 recent, earn/spend totals
Referrals:   Code, share, how-it-works
```
